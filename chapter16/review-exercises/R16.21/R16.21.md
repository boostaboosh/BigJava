R16.21
A deque (double-ended queue) is a data structure with operations addFirst,
removeFirst, addLast, and removeLast. What is the O(1) efficiency of these operations if the
deque is implemented as
a. a singly-linked list?
b. a doubly-linked list?
c. a circular array?

a) singly linked list
addFirst O(1)
removeFirst O(1)
(with last node ref)
addLast O(1)
removeLast O(1)
(without last node ref)
addLast O(n)
removeLast O(n)

b) doubly linked list
addFirst O(1)
removeFirst O(1)
(with last node ref)
addLast O(1)
removeLast O(1)
(without last node ref)
addLast O(n)
removeLast O(n)

c) circular array
addFirst O(1) amortised
removeFirst O(1) amortised
addLast O(1) amortised
removeLast O(1) amortised
